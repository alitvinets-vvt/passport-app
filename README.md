# Плановий Паспорт

Streamlit-застосунок для роботи з параметрами книжки з Google Sheets. Проєкт читає базові складові розрахунку (тарифи перекладу, редагування, формати, обкладинка, тири накладу тощо) і показує їх у веб-інтерфейсі для перевірки перед подальшою калькуляцією собівартості й РРЦ.

## Що входить до проєкту

- `app.py` — інтерфейс Streamlit
- `sheets_reader.py` — логіка читання та парсингу таблиці з Google Sheets
- `requirements.txt` — залежності Python
- `.env` — локальні секрети для розробки
- `.env.example` — шаблон змінних середовища для репозиторію

## Локальний запуск

1. Створіть віртуальне середовище:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

2. Встановіть залежності:

   ```bash
   pip install -r requirements.txt
   ```

3. Скопіюйте шаблон змінних і заповніть реальні значення:

   ```bash
   copy .env.example .env
   ```

4. Запустіть застосунок:

   ```bash
   streamlit run app.py
   ```

5. Відкрийте браузер за адресою:

   ```text
   http://localhost:8501
   ```

## Змінні середовища

Потрібні змінні в `.env`:

- `PASSPORT_SHEET_ID` — Google Sheet ID таблиці з параметрами
- `GOOGLE_SERVICE_ACCOUNT_JSON` — JSON облікового запису service account в одному рядку

Шаблон знаходиться в файлі `.env.example`.

## Важливі зауваження

- Файл `.env` не додається до git.
- Для production/деплою на Railway значення змінних задаються через Railway Variables.
- У репозиторії зберігається лише шаблон `.env.example` без секретів.
